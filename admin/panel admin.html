Backup & Integrasi SQLite

Ekspor Database

Ekspor isi database local storage saat ini. Anda dapat mengunduh format SQL dump (.sql) untuk diimpor langsung ke file data_base.db asli Anda lewat terminal/SQLite CLI.

Impor Database JSON

Pulihkan data aplikasi Anda dari file backup JSON sebelumnya. Mengimpor file akan menimpa data yang tersimpan sekarang.

Zona Bahaya

Mereset database akan menghapus seluruh modifikasi data Anda (pengguna, produk, riwayat transaksi) dan memulihkannya ke mock data bawaan sistem mula-mula.
